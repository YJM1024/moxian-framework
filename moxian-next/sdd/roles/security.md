# 安全与隐私

识别资产、数据用途、敏感性、入口、信任边界、身份和权限，覆盖注入/编码、输入业务逻辑、浏览器安全、API、文件、认证、会话、授权、令牌与联合身份、密码学、通信、配置、数据保护、日志错误及适用实时通道。控制深度由真实架构、威胁和项目义务决定。

根据实际变化选用对应条目。现有工程能力足够时直接使用，复用代码栏给出重复缺口应归属的位置。

## 9.1 在可信入口分别限制功能、对象与字段

用于新增详情接口、修改成员权限、增开后台入口。

- 工程入口　已有认证、策略引擎、数据库授权和服务端测试。
- 可复用代码　共用同一对象访问规则时集中到领域授权函数。
- 专业判断　安全与业务方确认谁能在何种状态读写哪些字段。
- 验收　允许主体成功，无权主体和另一租户被拒，输出字段符合约定。

采纳自ASVS 5.0.0-8.2.1 至 8.2.3 与 OWASP Authorization Cheat Sheet。[原文 1](https://github.com/OWASP/ASVS/tree/5cf9b032440be53ce345ab3c130fda46ba1ce7a2/5.0/en) [原文 2](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)

## 9.2 按实际身份方案明确会话、令牌受众、有效期和撤权边界

用于登录方式迁移、账号禁用、后台作业代表用户访问。

- 工程入口　已有身份提供方、令牌库、会话管理及测试租户。
- 可复用代码　多个入口使用相同验证策略时复用现有中间件配置。
- 专业判断　判断身份提供方和应用各自负责什么，撤权传播时间是否满足业务。
- 验收　目标环境中有效会话可用，终止、过期或用途错误的凭据按约定被拒。

采纳自ASVS 5.0.0 V6/V7/V9/V10。[原文 1](https://github.com/OWASP/ASVS/tree/5cf9b032440be53ce345ab3c130fda46ba1ce7a2/5.0/en)

## 9.3 按用途控制字段、缓存、日志及保留期限

用于新增个人资料、诊断日志、浏览器缓存、删除功能。

- 工程入口　平台访问控制、缓存策略、原有日志和生命周期配置。
- 可复用代码　多入口重复脱敏或清理时复用字段序列化和删除实现。
- 专业判断　负责人确定必要字段、保留期限、授权和例外。
- 验收　检查实际返回、缓存及日志样本，生命周期结束后到期数据按约定删除或限制访问。

采纳自ASVS 5.0.0-14.2.2、14.2.4、14.2.6、14.2.7 与 V16。[原文 1](https://github.com/OWASP/ASVS/tree/5cf9b032440be53ce345ab3c130fda46ba1ce7a2/5.0/en)

## 9.4 沿输入进入的解析器、业务层与最终输出逐段验证前提

用于富文本、文件上传、第三方消息、跨服务共享校验。

- 工程入口　成熟解析库、平台限制、现有输入与输出测试。
- 可复用代码　同一受信边界重复实现校验时提取公共模块。
- 专业判断　安全职责定位信任变化与未知路径，按适用章节补查专项。
- 验收　合法输入可用，约定拒绝的输入在预期边界被拒。缺少下游分析时保持待核查。

采纳自ASVS V1/V3/V4/V5 与 Trail audit-context-building 的调用追踪。[原文 1](https://github.com/OWASP/ASVS/tree/5cf9b032440be53ce345ab3c130fda46ba1ce7a2/5.0/en) [原文 2](https://github.com/trailofbits/skills/blob/149d7b21f4067765b82e67029730b42d228ef4b4/plugins/audit-context-building/workflows/audit-context.js)
