# 后端工程

定义输入、输出、协议状态、媒体类型、错误、身份认证与服务端授权，落实领域不变量、查询范围、事务、并发、幂等、顺序、超时、取消、重试、资源限制、日志和观测。保持使用方的源码、线协议及语义兼容；明确分页、完整导出、批量操作和异步作业的不同承诺。

根据实际变化选用对应条目。现有工程能力足够时直接使用，复用代码栏给出重复缺口应归属的位置。

## 5.1 明确每个入口的输入、输出、状态、媒体类型和身份要求

用于新接口、表单改为 JSON、公开字段或认证方案变化。

- 工程入口　已有 schema/lint、类型生成和服务端请求测试。
- 可复用代码　多个端点共享的参数校验、序列化或认证逻辑归现有中间件。
- 专业判断　后端决定公开语义，检验校验器对 format 等字段的实际支持。
- 验收　合法和非法请求得到约定状态与内容，真实 HTTP 行为与定义吻合。

采纳自OpenAPI 3.1.1 §4.8 Operation、Parameter、Responses、Media Type、Security Requirement。[原文 1](https://spec.openapis.org/oas/v3.1.1.html)

## 5.2 定义默认行为、排序与续页，分别检查源码、线上协议和业务语义

用于列表增加分页、枚举扩展、修改默认值或排序。

- 工程入口　现有 schema diff、旧版客户端与接口集成测试。
- 可复用代码　同类接口共享且语义一致时，复用分页解析和游标编码。
- 专业判断　后端与消费者决定空页、最后一页、兼容期及数据变动语义。
- 验收　旧消费者能完成原任务。按项目契约执行省略页长、零、负值、最大值和超出最大值的用例，核对状态、错误码或截断后的条数。覆盖同值排序、末页及空页；令牌分页按继续令牌判断结束，每次请求仍按当前身份授权。

采纳自AIP-158 分页、AIP-180 兼容。[原文 1](https://google.aip.dev/158) [原文 2](https://google.aip.dev/180)

## 5.3 使用稳定错误类型和已约定字段，HTTP 401 返回适用挑战

用于公开 API、跨语言客户端、认证拒绝或错误格式升级。

- 工程入口　HTTP 框架、原生客户端与接口测试。
- 可复用代码　共用错误格式时复用错误映射器。
- 专业判断　后端判断现有格式是否足够、哪些诊断只对服务端可见。
- 验收　客户端按结构处理错误，状态和响应内容一致，拒绝信息符合实际认证方案。

采纳自RFC 9457 §§3–5 与 RFC 9110 §15.5.2。[原文 1](https://www.rfc-editor.org/rfc/rfc9457) [原文 2](https://www.rfc-editor.org/rfc/rfc9110.html#section-15.5.2)

## 5.4 对并发写入声明不变量，区分事务内重试与外部副作用恢复

用于库存扣减、预约占位、批处理重试、重复回调。

- 工程入口　使用数据库约束、事务、队列或目标服务已有去重能力。
- 可复用代码　多个入口共享操作时，复用同一业务幂等处理与结果查询。
- 专业判断　后端确定重复调用的身份、超时后能否重试、何时补偿。
- 验收　并发和重复输入保持业务不变量，结果未知时能够查明，外部动作次数符合契约。

采纳自ASVS V2/V15 与 PostgreSQL §13.2。[原文 1](https://github.com/OWASP/ASVS/tree/5cf9b032440be53ce345ab3c130fda46ba1ce7a2/5.0/en) [原文 2](https://www.postgresql.org/docs/18/transaction-iso.html)
