# 墨线 SDD 框架

墨线是面向软件交付的规格驱动开发框架。仓库按版本组织，两个版本的文档、示例和工具分别放在各自的目录中。

| 版本 | 如何从需求走到验收 | 入口 |
| --- | --- | --- |
| 墨线 v2.0.0 | 按任务矩阵确定流程，以七个角色的分工、规则编号和阶段门禁组织交付。 | [使用说明](moxian-v2/README.md) · [规则总册](moxian-v2/docs/framework/MOXIAN.md) |
| 墨线下一版 | 从项目契约确定验收条件，按变更影响运行工程已有的测试。单个执行者可以按需查阅 11 个角色的专业要求。 | [使用说明](moxian-next/README.md) · [共同流程](moxian-next/sdd/skills/spec-driven-delivery/SKILL.md) |

`moxian-next/` 是下一版的暂用目录名，正式版本号待定。该目录内的 Python 工具包沿用包名 `sdd-framework`，包版本见 [pyproject.toml](moxian-next/pyproject.toml)。
