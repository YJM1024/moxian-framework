# 框架 v2 过程文档索引

本目录放 v2 的设计、施工、验收、日志、回滚与来源。下表按职责列出现行文件，一处内容只有一个落点。

| 文件 | 内容 |
|---|---|
| `DESIGN.md` | 设计方案，含「怎么实施」节 |
| `IMPLEMENT.md` | 施工记录与施工步骤 |
| `ACCEPT.md` | v2 验收结论、红项与证据指针 |
| `JOURNAL.md` | 冻结、批次解冻、发布与决定四类事件 |
| `CHANGELOG.md` | 版本变化摘要，v2.1.0 条目写最终口径 |
| `BACKLOG.md` | 未决与待承接事项 |
| `ROLLBACK.md` | 回滚方案与禁止项 |
| `ROLLBACK-DRILL.md` | 回滚演练记录 |
| `SOURCES.md` | 外部来源清单与引用位置 |
| `RESEARCH.md` | 调研与逐条摘录 |
| `sources/` | 七份原始采集表，按主题分文件保存 |

v2.0 的文书削减方案与域规则删除明细已由 v2.1 的单报告口径取代，不再单独保留计划文件。v1.7.5 的原文在 `../archive/v1.7.5/`，只读。
